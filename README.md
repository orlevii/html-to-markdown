# go-html-to-markdown

html-to-markdown is a tool that converts HTML content into Markdown format using a fast Golang backend.

## Example Usage
Below is a Python example of how to use the conversion:

```python
from go_html_to_markdown import html_to_markdown

html_content = "<h1>Hello, World!</h1>"
markdown_content = html_to_markdown(html_content)
print(markdown_content)  # Output: "# Hello, World!"
```
